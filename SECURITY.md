# Sicherheitsrichtlinie / Security Policy

## Schwachstelle melden / Reporting a vulnerability

Bitte melde Sicherheitslücken **vertraulich** an **security@sushiflux.dev** _(Platzhalter –
vor dem ersten Release durch die echte Adresse ersetzen, siehe docs/COMPLIANCE.md)_ und nicht
öffentlich (z.B. nicht als öffentliches Issue).

Please report security vulnerabilities **privately** to the address above, not publicly.

Hilfreich sind:
- betroffene Version (Einstellungen › Über),
- Beschreibung und Auswirkung,
- Schritte zum Nachvollziehen bzw. ein Proof of Concept.

## Was du von uns erwarten kannst

| Schritt | Frist |
|---|---|
| Eingangsbestätigung | innerhalb von 3 Werktagen |
| Erste Einschätzung (Schweregrad) | innerhalb von 10 Werktagen |
| Behebung kritischer/hoher Lücken | so schnell wie möglich, Ziel: 30 Tage |
| Veröffentlichung | nach Verfügbarkeit des Updates, mit Nennung der meldenden Person (auf Wunsch) |

Aktiv ausgenutzte Schwachstellen und schwerwiegende Sicherheitsvorfälle werden gemäß
EU Cyber Resilience Act (Art. 14) an die zuständige Stelle gemeldet.

## Unterstützte Versionen

Sicherheitsupdates erhält jeweils die **aktuelle Version**. Der Unterstützungszeitraum wird vor
dem ersten Release festgelegt und hier veröffentlicht.

## Geltungsbereich

Baton-Dienst, Oberfläche, Installer und das offizielle Plugin-SDK. Plugins von Drittanbietern
bitte direkt bei deren Autorinnen und Autoren melden.
