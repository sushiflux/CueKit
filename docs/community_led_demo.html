Wie funktioniert das CueKit Community-System?

Dieses Dokument zeigt dir Schritt für Schritt, wie aus einer simplen Text-Datei (JSON) ein fertiges Gehäuse mit "Notch" (Aussparung), leuchtendem Text und einem Button mit LED wird.

Teil 1: Die Plate (Gehäuse) mit Notch & Text

Schritt 1: Das JSON (Der Bauplan des Nutzers)

Der Community-Bastler lädt keine HTML-Datei hoch, sondern nur diesen Bauplan. Er sagt dem Programm, dass es eine "Notch" und einen "Text" gibt:

{
  "id": "my-notch-plate",
  "style": { "background": "#1e293b", "width": "500px", "height": "300px" },
  "ledZones": [
    {
      "id": "notch-led",
      "type": "box",
      "position": { "top": "0px", "left": "150px", "width": "200px", "height": "20px" },
      "shape": "notch"
    },
    {
      "id": "logo-text",
      "type": "text",
      "text": "STUDIO PRO",
      "position": { "bottom": "20px", "left": "150px", "width": "200px", "height": "30px" }
    }
  ]
}

Schritt 2: Das leere Gehäuse

React liest "width: 500px, height: 300px, background: #1e293b". Es zeichnet eine simple leere Box.

<div style="width: 500px; height: 300px; background: #1e293b;"></div>

Schritt 3: Die Notch (Aussparung) wird platziert

React liest jetzt das Array ledZones. Es findet das Objekt "notch-led". Es erstellt an den Koordinaten (top: 0, left: 150px) einen Container. Wir geben dem Container einen leuchtenden Rahmen (CSS Box-Shadow), der die Endnutzer-Farbe (z.B. Pink) annimmt.

<!-- React generiert diesen Code basierend auf dem JSON! -->
<div style="position: absolute; top: 0px; left: 150px; width: 200px; height: 20px;" 
     class="neon-box">
</div>

Schritt 4: Der LED Text kommt dazu

Als nächstes findet React die zweite LED-Zone: "logo-text". Anstatt einer Box rendert es ein Textfeld an (bottom: 20px, left: 150px). Der Text erhält ebenfalls die Farbe des Nutzers (hier: Violett) und leuchtet.

STUDIO PRO

Teil 2: Ein Custom Button mit LED

Schritt 5: Das JSON des Buttons

Gleiches Spiel für Tasten-Designs! Der Bastler definiert eine "ledZone" für den Button, z. B. einen Leuchtstreifen am oberen Rand.

{
  "id": "cyber-button",
  "style": { "background": "#0f172a", "borderRadius": "16px" },
  "ledZones": [
    {
      "id": "top-indicator",
      "type": "strip",
      "position": { "top": "4px", "left": "20%", "width": "60%", "height": "4px" }
    }
  ]
}

Schritt 6: Der Button wird gerendert

React baut zuerst die leere Taste (110x110 Pixel) und legt dann das Icon in die Mitte.

Schritt 7: Die Taste bekommt ihre LED

React liest die ledZones und packt das Licht-Div genau dorthin, wo das JSON es vorschreibt (top: 4px, left: 20%). Die Farbe ändert sich dynamisch je nach Tasten-Zustand (z.B. Grün für aktiv).

Die goldene Regel:

Das Programm versteht den JSON-Code, weil wir Programmierer vorher in React eine Komponente geschrieben haben, die als Übersetzer fungiert.

React iteriert einfach über die Liste ledZones und baut für jeden Eintrag einen <div>-Container. Dabei weist React dem CSS-Attribut style exakt die Koordinaten zu, die im JSON stehen.
