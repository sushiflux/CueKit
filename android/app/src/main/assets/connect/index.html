CueKit

Läuft CueKit schon auf deinem PC?

Diese App ist die Fernbedienung. Die Software läuft auf deinem Windows-PC, dieses Gerät verbindet sich nur damit.

  1. Installiere CueKit auf deinem Windows-PC. Du findest die Windows-Version im Microsoft Store.
  2. Starte CueKit auf dem PC.
  3. Komm zurück in diese App und wähle „Ja, jetzt verbinden“.
Mehr Informationen:

Mit deinem PC verbinden

Öffne auf dem PC Geräte → Gerät koppeln. Dort erscheint ein QR-Code. Das Handy muss im selben WLAN sein wie der PC.

Beides steht im Fenster „Neues Gerät koppeln“ auf dem PC. Der Code gilt 5 Minuten und nur einmal.
